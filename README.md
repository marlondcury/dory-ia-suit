#  Dory AI Suite - YouShop Project

Sistema de microsserviços para automação de marketing e recuperação de vendas em tempo real.

##  Arquitetura do Projeto
- **Python (Pandas):** Inteligência de dados e higienização (LGPD).
- **Node.js (AWS):** Gateway de segurança e autenticação de API.
- **n8n + Groq (Llama 3.1):** Orquestração de IA com latência ultra-baixa e custo zero.
